派生规则：每档纸色由该档专属专色在 HLS 空间派生 —— 保色相不变、明度固定 0.880、饱和度 = 专色饱和度 × 0.55（下限 0.20）。不采用「与白色线性混合」：该做法会把各档一起推向中性灰、丢失色相辨识度，使纸色之间不可区分。
对比度：专色文字（面额数字、机构名、徽志等）在其自身纸色上的实测对比度依次为 6.56 / 6.33 / 7.21 / 10.42 / 4.50 / 11.56，全部 ≥ 4.5 : 1（WCAG 2.1 AA，规范书 6.4.1）；最低一档为 ₮200,000,000 的 4.50，仍达标。
用色影响：每档纸色为一张淡网，单面实际用色由 6–8 个升至 7–9 个专色，仍在规范书「单面 6–10 专色」区间内。
压印浅字色：每档另配一个自该档专色派生的浅字色（规范书 4.4.6 同表），六档依次为 #91AEC0 / #91C0B9 / #A299B8 / #8F98C1 / #C1A88F / #B8AF98，用于「DeepSeek」压印字与压印年份；其在本档纸色上的对比度仅 1.60 ~ 2.05 : 1 —— 属有意压淡的印迹，不承担识别功能，不适用 4.5 : 1 对比度红线，也不受字号下限约束。
规则出处：压印浅字色的派生规则见规范书 4.4.6（保留色相 / 明度 0.660 / 饱和度 S = max(专色 S × 0.55, 0.18)）—— 其下限 0.18 与纸色的 0.20 不同，两者不得混用，且该下限并非空条款：六档中 50,000,000 档 #4A3A6E 同时触及两个下限（纸色取 0.20、压印浅字色取 0.18），500,000,000 档 #2E2717 纸色取 0.20、压印浅字色取 0.1833。派生规则正文以规范书为准，本图不重复定义。
