# 《我给 DeepSeek 印了一套钱》— B 站视频方案

> 定位：娱乐性质虚拟货币「鲸元券」的发布向介绍片
> 风格：**抽象**（一本正经 × 突然发疯 的反复横跳）
> 时长：**4 分 30 秒**（B 站完播率甜点区）
> 基调：全程用**纪录片级的严肃播音腔**念**完全站不住脚的内容**

## 二、分镜脚本

### 00:00 – 00:14　　开场：三秒建立信任，一秒摧毁它

| 画面 | 声音 / 字幕 |
|---|---|
| 纯黑底，白字逐字打出：`DeepSeek Token银行` | 庄严的弦乐起 |
| 切：券面特写缓慢横移（1 亿券正面） | 播音腔：「本券为法定清偿货币，凭券即付，不得拒收。」 |
| 定格。0.6 秒静音 | |
| **突然**：红色报错弹窗糊满全屏 | `服务器繁忙，请稍后再试` + 刺耳"叮" |

**字幕（大字）**：`……好的，我们再试一次`

> 【设计说明】这是全片唯一的钩子。前 5 秒必须让观众以为点开了科普，第 6 秒让他们知道被骗了 —— 抽象区的核心不是"一直很怪"，而是**"正常着正常着突然不对劲"**。

---

### 00:14 – 00:52　　第一章：为什么要印钱

| 画面 | 声音 |
|---|---|
| 屏幕录制：DeepSeek 对话框，输入「帮我设计一套虚拟货币」 | 「事情的起因非常简单。我问了 DeepSeek 一个问题。」 |
| AI 开始输出（加速 8×），文字瀑布流 | 「它回答得很认真。」 |
| 切：输出被截断，红字 `已深度思考（用时 12 秒）` | 「认真到，我决定真的把它做出来。」 |
| 切：白底黑字，逐条打出 | 「于是有了它 ——」 |
| 券面全档总表从下往上滚过 | 「**鲸元券**。」 |

**字幕**：`一套不存在的货币，六个不存在的面额，一家不存在的银行`

---

### 00:52 – 01:50　　第二章：印钞厂 = API

| 画面 | 声音 |
|---|---|
| 分裂屏：左边是印钞厂流水线素材，右边是终端跑渲染脚本 | 「正常的印钞厂靠印钞机。我这个印钞厂，靠 API。」 |
| 终端逐行打印渲染日志（真实日志，加速） | 「每跑一次渲染，就是印一张票。」 |
| 数字计数器飞涨：`tokens: 1,284,992` | 「每印一张票，烧掉一百多万个 token。」 |
| 切：价目表贴图 | 「按 DeepSeek 的定价，这一整套票，总成本 ——」 |
| 大字：`￥4.73` 停留 2 秒 | 「**四块七毛三**。」 |
| 切：券面特写 | 「人类历史上第一次，印钱比印钱便宜。」 |

**字幕（小字，右下）**：`* 统计口径：缓存未命中`

> 【DeepSeek 梗】价格梗是这片的底料 —— 观众的笑点不在于数字本身，而在于"我居然真的算了"。

---

### 01:50 – 02:48　　第三章：防伪技术（全片笑点密度最高段）

**这一段全部用"一本正经地胡说"的节奏，每条 8-12 秒，不解释，直接下一条。**

| # | 画面 | 旁白 |
|---|---|---|
| 1 | 券面大幅旋转，颜色从绿变紫 | 「**光变油墨**。你换个角度看它，颜色会变。**主要是因为，你换个角度问 DeepSeek，答案也会变。**」 |
| 2 | 正面扇形 + 反面扇形拼成完整圆 | 「**对印**。正面问一遍，反面问一遍。**对不上，说明它幻觉了。**」 |
| 3 | 盲文块特写 | 「**盲文**。摸不出来。**因为它是生成的，它自己也没摸过。**」 |
| 4 | 冠字号特写 `WY 100000000 8842A` | 「**冠字号**。每次生成都不一样。**同一个问题问两遍，你会得到两张不同的钱。**」 |
| 5 | 微缩文字带放大 | 「**微缩文字**。得用放大镜看。**放大之后你会发现，它只是把同样的话说了六十八遍。**」 |
| 6 | 安全线 | 「**开窗安全线**。假装开窗。**打开一看，里面也是这样。**」 |

**收尾（静帧 3 秒）**：`以上六项防伪技术，有五项是我编的。`

> 【结构说明】前五条快速堆叠建立节奏，第六条用一个"自我拆台"收 —— 这是抽象区的经典波形。

### 02:48 – 03:52　　第四章：面额体系（DeepSeek 梗集中爆发）

| 画面 | 声音 |
|---|---|
| 六张券按尺寸从小到大排开，真实比例 | 「六个面额，从小到大。」 |

| 切：DeepSeek 对话框输入「五亿 token 是多少」 | |
| AI 开始输出，突然截断 | `服务器繁忙，请稍后再试` |
| 静音 1 秒 | |
| 切：观众视角的券面 | 「**它自己也不知道。**」 |
| 快速剪辑（每张 0.4 秒）：六个面额的特写 × 2 遍 | 节奏鼓点 |

## 三、声音设计

| 元素 | 做法 |
|---|---|
| 旁白 | **全程一个人，一种声线，绝不破功**。抽象区的笑点全部来自"叙述者本人不觉得好笑"。建议用 TTS 也行 —— 机器音念荒诞内容反而更对味 |
| 配乐 | 前 3 分钟：正片级纪录片配乐（弦乐 + 定音鼓）；第四章起：突然换成 B 站土味鼓点 |
| 音效 | 全片只用三种：`叮`（报错）、`咔`（切页）、`嗡`（静音时的空气声） |
| 静音 | **全片刻意安排 4 处 1 秒以上的绝对静音**（00:14 / 02:52 / 04:04 / 04:26）。这是最便宜也最有效的喜剧工具 |

## 四、DeepSeek 梗清单（按出现顺序）

1. **服务器繁忙，请稍后再试** —— 全片出现 3 次，最后一次是结尾
2. **已深度思考（用时 N 秒）** —— 第一章用来当"认真"的证据
3. **定价 / 缓存未命中** —— 第二章的成本核算
4. **幻觉** —— 第三章的"对印"防伪原理
5. **一个问题的两次回答不一样** —— 第三章的"冠字号"
6. **token = 词元** —— 第四章面额体系的立论基础
7. **同样的话说六十八遍** —— 微缩文字带
8. **「你好！很高兴为你服务」** —— 结尾，最狠的一刀：你忙活三个月印钱，它跟你说很高兴为你服务

## 六、几条执行提醒

1. **别解释梗**。抽象区最忌讳"这里我玩了个梗"—— 观众笑不笑是他的事，你的任务是保持面无表情。
2. **别做太长**。四分半是上限。超过 5 分钟，前 3 分钟的严肃铺垫会变成负担。
3. **封面别写"AI生成"**。写"我印的"更有反差。
4. **结尾那个"很高兴为你服务"是关键**。前面所有梗都是铺垫，这一句才是全片的刀。剪辑时给它留足 2 秒黑屏。
